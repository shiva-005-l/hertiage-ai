# Feature Spec: Heritage Chatbot

## Description

An AI-powered chatbot that provides information about heritage sites.

## Scenarios

### Scenario 1: Asking for Information

- **Given** the user has opened the chatbot
- **When** the user asks "Tell me about the Taj Mahal"
- **Then** the chatbot should provide accurate historical information about the Taj Mahal

### Scenario 2: Asking for Directions

- **Given** the user is interacting with the chatbot
- **When** the user asks for directions to a monument
- **Then** the chatbot should provide location details or a link to maps
