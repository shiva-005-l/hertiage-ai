# HeritageAI Frontend

Next.js App Router frontend for the Smart Heritage Guide.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Important Folders

- `src/app` - Next.js routes, pages, layouts, and frontend API adapters
- `src/components` - reusable UI and feature components
- `src/hooks` - React hooks and context providers
- `src/services` - frontend services, local data, and API-facing utilities
- `src/styles` - reserved for shared style modules
- `src/utils` - small helper functions
