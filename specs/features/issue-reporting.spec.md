# Feature Spec: Issue Reporting

## Description

Allows users to report maintenance issues or vandalism at heritage sites.

## Scenarios

### Scenario 1: Submitting a Report

- **Given** the user is on the report page
- **When** the user fills in the details and clicks "Submit"
- **Then** the report should be saved and a confirmation message displayed

### Scenario 2: Attaching a Photo

- **Given** the user is filling out an issue report
- **When** the user attaches a photo of the issue
- **Then** the photo should be uploaded with the report
