# Feature Spec: Voice Guide

## Description

Provides audio tours and descriptions for monuments.

## Scenarios

### Scenario 1: Playing Audio

- **Given** the user is on a monument details page
- **When** the user clicks the "Play Voice Guide" button
- **Then** the audio description should start playing

### Scenario 2: Changing Language

- **Given** the user is listening to a voice guide
- **When** the user selects a different language
- **Then** the audio should switch to the selected language
